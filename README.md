## Description

**pyheritage** — A Python library providing typed Pydantic models for standard ontologies for describing cultural
heritage, archival documents, and bibliographic resources

In the current version implements:
* [CIDOC-CRM 7.0]()
* [Dublin Core]()

## Installation

    pip install pyheritage
